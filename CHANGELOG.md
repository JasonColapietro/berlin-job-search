# Changelog

## 0.1.0 — 2026-10-23

- Added Germany-specific job search from Bundesagentur für Arbeit, Daily Berlin Jobs, Arbeitnow and public company ATS boards.
- Added German-language, salary, visa-threshold, seniority, work-mode and posting-integrity analysis.
- Added German Lebenslauf and Anschreiben templates, English CV and cover-letter templates, PDF rendering and ATS checks.
- Added local application tracking, follow-ups, archive workflow and an offline HTML dashboard.
- Added mock-interview and drafter–reviewer application workflows.
- Added a read-only ChatGPT MCP server, portable plugin package, and multi-agent skill discovery.
