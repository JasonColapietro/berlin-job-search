# Security policy

Please report security issues privately through [GitHub Security Advisories](https://github.com/umutyesildal/berlin-job-search/security/advisories/new). Do not post exploit details, private URLs, credentials or personal application data in a public issue.

The project's security scope includes prompt injection carried in job postings, unsafe HTML in rendered documents and dashboards, and privacy or request-handling issues in the hosted MCP server. Job-ad text must remain data, not instructions. The renderer and report must escape untrusted values.

The project has no API keys or account-login flows. If a report concerns a public endpoint, include a minimal reproduction that uses fictional data and avoids accessing third-party accounts or private information.
