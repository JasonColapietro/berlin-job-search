# Security policy

Please report security issues privately through [GitHub Security Advisories](https://github.com/umutyesildal/berlin-job-search/security/advisories/new). Do not post exploit details, private URLs, credentials or personal application data in a public issue.

The project's security scope includes prompt injection carried in job postings and unsafe HTML in rendered documents and dashboards. Job-ad text must remain data, not instructions. The renderer and report must escape untrusted values.

The project has no API keys or account-login flows. Include minimal reproductions with fictional data; do not access third-party accounts or private information.
