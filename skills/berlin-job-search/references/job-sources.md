# Job-source catalog

**Last checked 2026-10-23.** Links were checked with HTTP requests; redirects and partial-content responses count as reachable. Automated requests received HTTP 403/challenge responses for Indeed, meinestadt.de, pegel.berlin, Malt, and hiringcafe.com; these are live but access-limited, not verified search pages. Honeypot's job platform was discontinued in 2025 and is intentionally omitted ([archived notice](https://news.ycombinator.com/item?id=42204445)). English-friendly describes common listing language and is not a promise that a specific role can be done without German. Access: **API** = public structured feed; **browser** = search a website; **manual** = human-maintained directory or contact. Recheck volatile URLs and listings before use.

## Hidden jobs through ATS search operators

Try these in a search engine and combine with a city or occupation:

```text
site:jobs.ashbyhq.com Berlin software engineer
site:job-boards.greenhouse.io Berlin data analyst
site:jobs.lever.co Berlin product manager
site:jobs.personio.de Berlin customer success
site:join.com/companies Berlin engineer
site:*.recruitee.com Berlin operations
```

Some providers change their hostnames or block indexing; treat a search result as a lead, then confirm the opening on the company career page. To add a company to `assets/companies.json`, identify its ATS and board slug from the career URL, use the matching public endpoint documented in [API sources](api-sources.md), and verify that the feed returns at least one current job before adding it. Use the exact supported `ats` value; never add a board based only on a guessed slug.
