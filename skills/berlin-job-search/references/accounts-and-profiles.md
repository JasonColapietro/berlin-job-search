# Accounts and profiles: human-guided setup

The agent can help draft text, prepare a checklist, compare privacy settings, and review wording. **The human creates and controls every account.** The agent never creates accounts, enters passwords, handles recovery codes or 2FA, solves CAPTCHAs, or impersonates the user.

## LinkedIn

1. Visit [LinkedIn](https://www.linkedin.com/), choose Join now, and follow the current identity and email/phone verification flow yourself. Use a professional email address you control.
2. Add a clear headline with a target role, specialty, and location/work authorization only if accurate: `Senior Backend Engineer | Java, AWS, platform reliability | Berlin`.
3. Write an About section in first person: what work you do, evidence of impact, target roles, and languages. Avoid empty keyword lists and claims you cannot substantiate.
4. Add roles in reverse chronological order, with outcomes and scope. List specific skills that you can discuss in an interview.
5. Set the profile location to the intended search city and add an “Open to Work” target location/role set. Choose whether to share it with recruiters only or with all members; the public option can display the green profile frame. LinkedIn says recruiter-only visibility is not guaranteed to be completely private; review the current [Open to Work visibility guidance](https://www.linkedin.com/help/linkedin/answer/a507508).
6. Where useful, create a second-language profile (for example English and German). LinkedIn profile language versions are separate text; keep dates and facts consistent. See [add or edit a profile in another language](https://www.linkedin.com/help/linkedin/answer/a541878).
7. Turn on a small set of useful job alerts; review frequency and location filters so your inbox stays actionable. See [job alerts](https://www.linkedin.com/help/linkedin/answer/a507441).
8. Treat Easy Apply as an application workflow, not a quality signal. Review the actual destination, uploaded file, answers, privacy disclosures, and consent before any submission.
9. Connect with a short, relevant note. Ask for a small, specific conversation; do not mass-send requests. Never claim a referral or relationship that does not exist.

### Drafting a Germany-ready LinkedIn profile

**Headline formula:** target role + specialty/evidence + target city or work model. Examples are patterns, not claims to copy without checking:

- English: `Data Engineer | Python, SQL, cloud data platforms | Berlin`
- Deutsch: `Data Engineer | Python, SQL und Datenplattformen | Berlin`
- Career change: `Operations Analyst transitioning to Data Analytics | SQL, dashboards, process improvement`

**About section formula:**

1. State the kind of problem you solve and the roles you are targeting.
2. Give one or two concrete outcomes from the profile/CV that you can explain.
3. Name a small number of relevant tools or domain areas.
4. State languages and location/relocation preference accurately; omit work-authorization details from public text unless the user wants them visible.

Do not paste the same generic paragraph into every language version. Have a fluent speaker check nuance in German; use CEFR or accurately self-described levels rather than “fluent” if that overstates ability.

**Skills section:** order the most relevant real skills first, choose standard LinkedIn skill labels when available, and request endorsements only from people who can honestly support them. Add projects only when the user can discuss their own contribution.

### Export your LinkedIn profile to draft `cv.md`

The human can export profile information and ask an agent to organize it into `job-search/cv.md` for review:

1. On desktop, open **Me → View profile → More or Resources → Save to PDF**. LinkedIn says this option may not be available to everyone and currently requires the profile language to be English; it is not available in the mobile app. [LinkedIn Help: Save a profile as a PDF](https://www.linkedin.com/help/linkedin/answer/a541960).
2. For a structured archive, open **Me → Settings & Privacy → Data privacy → How LinkedIn uses your data → Download your data** (sometimes presented as **Get a copy of your data**), choose only the categories needed, and request the archive. LinkedIn emails the download link; the archive is available for 72 hours. [LinkedIn Help: Download your data](https://www.linkedin.com/help/linkedin/answer/a1339364).
3. The user chooses what file, if any, to share locally. The agent may convert the supplied profile details into `job-search/cv.md`, but it must ask the user to confirm every fact, date, role, skill, and qualification before treating the draft as accurate.

The export can include personal information. Keep it in a private local folder, remove irrelevant contact or connection data, and do not upload it to an untrusted service. An agent never signs in or downloads the archive for the user.

## Job alerts, profile visibility, and application settings

- Create separate alerts for materially different target roles instead of one alert with unrelated keywords. Recheck city, radius, recency, and workplace filters whenever LinkedIn changes its UI.
- Check the application CV separately from a profile upload. LinkedIn says uploaded application resumes may be retained for reuse; choose and remove those files yourself. [Resume settings](https://www.linkedin.com/help/linkedin/answer/a510363).
- Review search-engine visibility and contact details in privacy settings. A public professional profile and a private phone number are compatible choices.
- Before Easy Apply, compare the stored CV and answers with the current role; do not leave an old phone number, location, salary, or work-authorization answer.
- If a job redirects to an employer or third-party site, check the domain and data/privacy notices before uploading.

LinkedIn's [job-alert guide](https://www.linkedin.com/help/linkedin/answer/a507441) explains notifications; use it to verify the current UI rather than relying on remembered button positions.

## XING: current 2026 role

XING remains active as a German-speaking **jobs network**, with job search, profile discovery, recruiter contact, and employer recruiting products. It is no longer best described as a broad professional social-feed network: New Work SE describes the repositioning toward a jobs network and XING says its focus is matching and job search. The official XING help pages still describe searchable profiles, recruiter-visible job preferences, job recommendations, and XING Jobs. Sources: [XING's current job-search guide](https://help.xing.com/hc/en-us/articles/31499161470237-Find-your-new-job-with-XING), [job preferences](https://help.xing.com/hc/en-us/articles/31499254751133-Modify-your-job-preferences), and [New Work SE: XING strategy](https://new-work.se/en/newsroom/press-releases/2025-petra-von-strombeck-hands-over-chairmanship-of-managing-board).

1. Join or sign in manually at [XING](https://www.xing.com/); do not share access with an agent.
2. Complete profile basics, employment history, skills, and preferred roles. Check visibility controls before adding phone, address, birthday, or contact details.
3. Set job-seeker status and job preferences (titles, cities, salary expectations, career level, working hours, workplace model, and industries). Official guide: [modify job preferences](https://help.xing.com/hc/en-us/articles/31499254751133-Modify-your-job-preferences).
4. Search XING Jobs and save relevant alerts or preferences yourself; verify that listing details lead to the employer's current vacancy.
5. Prefer concise, contextual recruiter contact. XING's own help says job preferences are intended for recruiter matching and describes automatic exclusion of the current employer for these settings; check the live privacy wording before relying on it.

## StepStone, Indeed, and public services

- **StepStone:** create a profile at [StepStone Germany](https://www.stepstone.de/), upload a CV if you want recruiters to find it, and configure Jobagent alerts. Check profile discoverability and document visibility. Do not assume an uploaded CV is visible only to one employer.
- **Indeed:** at [Indeed Germany](https://de.indeed.com/), maintain a current CV and job preferences; check whether a listing is direct-employer or agency-posted. Indeed may redirect to an employer's site.
- **Agentur für Arbeit:** the public [Jobsuche](https://www.arbeitsagentur.de/jobsuche/) can be searched without creating an account. Create an online account yourself only if you want eServices such as job-seeker registration or benefit-related tasks. The official [eServices overview](https://www.arbeitsagentur.de/eservices) explains available services; identity verification may be required.
- **Make it in Germany:** use the federal portal's [job listings](https://www.make-it-in-germany.com/en/working-in-germany/job-listings) and [visa information](https://www.make-it-in-germany.com/en/visa-residence). It is also useful for international candidates.
- **EURES:** use [EURES job search](https://eures.europa.eu/jobseekers_en) for European cross-border listings and mobility support.
- **kununu / Glassdoor:** use [kununu](https://www.kununu.com/) and [Glassdoor Germany](https://www.glassdoor.de/) as research inputs for employer reviews, salary context, and interview reports. Reviews are self-selected and may be out of date; verify material facts with the employer.

### StepStone profile and Jobagent

1. Create and verify the account yourself; use the same professional email you monitor for applications.
2. Add role titles, work location/radius, and employment type; upload a current CV only if you are comfortable with its discoverability.
3. Create separate Jobagent searches for distinct role families (for example, backend engineering and data engineering) rather than mixing them into one broad alert.
4. Reopen each alert to confirm the city, freshness, seniority, and contract filters have not been reset.
5. Remove or replace outdated CV files from profile settings after the human reviews the change.

## Indeed profile and eServices

- On Indeed, compare the public profile/CV setting with a one-off upload to a job. A profile that is discoverable to employers is different from a single application attachment.
- Check whether an ad redirects to a staffing agency or the hiring company. Confirm the legal employer and posting date before adding it to the tracker.
- If the job is direct-employer, continue on the employer's official site and review the privacy/data-retention notice there.
- For BA eServices, create and verify an account manually only for services you need (for example, job-seeker registration or benefit claims). Identity verification may be required; never give an agent a BundID password, eID PIN, or recovery code. [BA eServices](https://www.arbeitsagentur.de/eservices).

## International job-search profiles

- **Make it in Germany:** use the portal to discover employers and understand work-permit routes; it is not a replacement for the responsible Ausländerbehörde or mission.
- **EURES:** search cross-border roles and mobility support, then confirm German payroll country, work location, and permit conditions with the employer.
- **kununu / Glassdoor:** look for repeated themes rather than treating one review as a verified company fact. Compare the review date, role, and location.
- **Public-sector portals:** keep a German-language version of role titles and qualifications available; public postings may require formal recognition or additional eligibility evidence.

## Profile checklist

- [ ] Same accurate dates, titles, and employers across platforms and CV.
- [ ] A location and relocation/remote preference that match the real plan.
- [ ] German and English text checked for meaning, not merely literal translation.
- [ ] Role titles and skills mirror relevant ad language only when truthful.
- [ ] No passport number, tax ID, bank details, or residence-card scan in public profile fields.
- [ ] Recruiter visibility and public search-engine visibility reviewed.
- [ ] Job alerts are narrow enough to review consistently.
- [ ] No misleading “Open to Work” promise or unapproved public frame.
- [ ] User has reviewed every saved change before publishing.

## Profile maintenance routine

- Review role dates and titles after each role change; do not wait until an application deadline.
- Recheck target cities and remote preference after a relocation plan changes.
- Remove stale, confidential, or non-public portfolio material.
- Review visibility of contact information, activity notifications, and uploaded CVs after platform settings change.
- Refresh job alerts when the role family, seniority, or commute radius changes.
- Ask a trusted person to review translated German text for tone and meaning.
- Keep a local copy of the final profile text in a private file so changes can be reviewed before publishing.
- Do not use a public post to reveal that a current employer is about to end employment unless the user explicitly wants that disclosure.

## Security and privacy checklist

- Use a unique password and enable the platform's own security protections yourself.
- Keep recovery email/phone current and store recovery codes in a password manager you control.
- Review third-party app access periodically; remove services you no longer use.
- Do not share login links, one-time codes, browser cookies, or ID scans with a recruiter or an agent.
- Use a separate professional email if it helps compartmentalize applications, but keep access under your control.
- Check the URL and company domain before following a recruiter message or uploading a CV.
- Treat job-search availability as personal information; choose recruiter-only or public status deliberately.
- Remove public contact details that are not needed for hiring.
- Before downloading a platform archive, request only the categories needed for the CV draft and keep the archive local.
- If an account is compromised, use the platform's official recovery process; do not hand credentials to a third-party “recovery” service.

The agent may help make a privacy checklist but cannot log in, change a setting, accept a consent dialog, or download profile data for the user.

## Message and action safety

Agents may draft profile text and messages using the templates in `assets/outreach-templates.md`. The user must verify names, facts, and recipient context. Stop and hand control to the user if a site requests login, CAPTCHA, 2FA, consent, or personal data. Never click Apply/Submit/Send, set an alert, save a job, or change profile visibility without the user's explicit confirmation for that action.
