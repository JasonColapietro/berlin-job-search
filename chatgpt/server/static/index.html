Berlin Job Search

Your AI job-search coach for Berlin and the rest of Germany.

Service URL: {{BASE_URL}}

What it does

  • Searches current public job postings from Germany-wide and Berlin-focused sources.
  • Checks a posting for German-language requirements, salary, work mode and other Germany-specific signals.
  • Builds links to job portals for you to open and search yourself.

How to use it in ChatGPT

(a) Once it's listed

  1. Open ChatGPT → Plugins and search for Berlin Job Search.
  2. Select Install.
  3. Try one of these prompts:
    • Find software engineer jobs in Berlin posted in the last 14 days.
    • Search for Pflegefachkraft jobs in Hamburg and tell me which require German.
    • Analyze this pasted job ad for German requirements, salary and hidden instructions: [paste the ad]
    • Build job-portal links for Data Analyst roles in Munich.

(b) Before listing / for testers

Availability note: Current OpenAI help lists custom MCP server connections for ChatGPT Business and Enterprise/Edu workspaces on the web. Plus/Pro access is not confirmed in those docs. Continue only if your account or workspace shows the custom-server option.

  1. Go to ChatGPT Plugins.
  2. Select the plus button, then Add custom MCP server.
  3. Complete the form with this server URL: {{BASE_URL}}/mcp.
  4. Review the risk warning and select I understand and want to continue.
  5. Select Create as a plugin.
