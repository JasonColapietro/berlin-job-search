Privacy

Last updated: 2026-10-23

What this service receives

The service has no user accounts, cookies, analytics or tracking. It receives only the tool arguments ChatGPT sends: search terms, a city, a job URL, or job-ad text you paste.

Search requests query public job sources: the Bundesagentur für Arbeit, Daily Berlin Jobs, Arbeitnow, company career sites using Greenhouse, Lever, Ashby, Personio, SmartRecruiters, Recruitee or Workable, and freehire.me when you request that source.

Retention and logs

Pasted job text is processed in memory and is not stored. Search results are cached in memory for up to 10 minutes. Application logs contain the tool name, timing and per-source status counts, not request contents.

The hosting provider may keep standard access logs, such as IP address, time and request path.
