# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short, be welcoming and respectful, assume good intent while addressing impact, accept constructive feedback, and avoid harassment, discrimination, personal attacks or publishing another person's private information.

For conduct concerns, contact the maintainers through [GitHub](https://github.com/umutyesildal/berlin-job-search/issues). For security concerns, use [GitHub Security Advisories](https://github.com/umutyesildal/berlin-job-search/security/advisories/new) instead.
